ST Small Town Guide

Website Planning Document

Site Name

Small Town Guide

I chose the name "Small Town Guide" because the website will provide useful information about a small town or neighborhood. The name is simple and clearly describes what visitors can expect to find on the website.

The website will help residents and visitors discover local businesses, learn about the town's history, and communicate through the contact and feedback page.

Site Purpose

The purpose of the Small Town Guide website is to provide useful information about a local community in one organized online resource.

The website will provide information about local businesses, an interactive history timeline, and a contact and feedback form. The goal is to make it easier for residents and visitors to find useful information about the community.

Scenarios

The following questions represent things that visitors to the website might want to know:

  • What local businesses are available in the town?
  • Where can I find a restaurant, coffee shop, bookstore, or hardware store?
  • What important events have happened in the town's history?
  • How can I learn more about a specific historical event?
  • How can I send a question or feedback about the community?

Planned Website Pages

  1. Home Page:

    The home page will introduce the town and provide a brief overview of the community. It will include a hero image and navigation links to the other pages.

  2. Local Businesses Page:

    This page will feature profiles of 5–6 local businesses, such as restaurants, coffee shops, bookstores, and hardware stores.

    Each business will include a photo, description, hours, and location information. JavaScript will be used to create a simple search and filter feature so visitors can narrow the businesses by category.

  3. History Timeline Page:

    This page will display a visual timeline of important events in the town's history, including its founding, major buildings, and important local milestones.

    JavaScript will allow visitors to click on timeline events to reveal additional information about each event.

  4. Contact / Feedback Page:

    This page will contain a form where visitors can submit questions or feedback.

    JavaScript will be used for client-side validation to check that required fields are completed, the email address has a valid format, and the message meets a minimum length before the form can be submitted.

JavaScript Features

JavaScript will be used to make the website interactive and useful to visitors.

  • A search and category filter will be used on the Local Businesses page.
  • The History Timeline page will allow visitors to click on events to display additional information.
  • The Contact / Feedback page will use client-side JavaScript validation.

Why I Chose This Subject

I chose this subject because I want to create something that could be genuinely useful to a real community instead of making a website that is only a practice exercise.

Small towns may not always have one organized online resource where residents and visitors can easily find information. This website could help bring useful information together in one place.

This project also gives me a good opportunity to demonstrate the skills I have learned in the course. I will use HTML and CSS to create responsive and well-organized pages, JavaScript for the interactive timeline and business search and filter feature, and JavaScript form validation for the contact page.

Finally, I chose this topic because it gives me plenty of real-world content to work with. This will allow me to focus on creating a functional, organized, and user-friendly website while practicing the skills I have learned in the course.
